# 販促キット v1

LPと合わせて使う、紙・LINE・対面の素材集。**共通の考え方は「機能を売らない。案件を見せる」**。

---

## 0. 全体で守ること

| 原則 | 理由 |
|---|---|
| **実際の案件を出す** | 抽象的な便利さより、案件1件の方が登録される |
| **機能名を並べない** | 「多機能＝難しそう」になる |
| **人工で換算する** | 建設業は全部を人工単価で考える |
| **「全部使わなくていい」と言う** | 使いこなせない不安を先に潰す |
| **数字は具体的に** | 「1,240㎡・翌月末払い・¥1,860,000」が効く |

**キャッチは1本に統一する。**

> ## 次の現場、決まってますか。
>
> （サブコピー）全国の下請案件が、毎週あたらしく入ります。公共事業も民間工事も。
> 何次下請かも、金額も、応募する前に分かります。

### 言ってはいけないこと

| ✕ 言わない | 理由 |
|---|---|
| 「元請から直の案件だけ」 | **2次・3次の案件も載る。** 誇大になる |
| 「公共事業専門」 | 民間工事も同じだけ扱う |
| 「中間マージンなし」 | 2次・3次があるので嘘になる |
| 「公共工事」 | 表記は**「公共事業」**で統一 |

### 代わりに言うこと

> 1次も2次も3次もあります。だから、案件ごとに必ず出します。
> 運営が出す案件は元請直が中心です。

**正直に出すことが、そのまま差別化になります。**
他のサイトは何次か分からないまま問い合わせるしかない。そこが一番の不満なので、
「隠さない」だけで強い訴求になります。

## 4. 営業トーク

### 4-1. 協力業者（足場屋・塗装屋）向け

**掴み（15秒）**
> 「次の現場、もう決まってますか。
> 下請案件のアプリなんですけど、何次下請かも金額も先に分かります。
> 登録は無料です。今すぐ画面で見せられます」

**その場でスマホを見せる。** 説明より画面。

**よくある反応と返し**

| 言われること | 返し |
|---|---|
| 「今、仕事は足りてる」 | 「じゃあ逆に、手が空く時期だけ出しておいてください。無料です。声が掛かったら考えればいいので」 |
| 「アプリは苦手で」 | 「最初は3つしか画面がありません。案件を見るだけなら、ヤフーの画面より簡単です」 |
| 「登録料いくら？」 | 「無料です。案件も見られます。月2,980円は書類まで使いたい人だけ」 |
| 「うちは元請から直で来るから」 | 「その元請さんとの注文書と請求書、こっちで作れます。紙とFAXやめられますよ」 |
| 「怪しくない？」 | 「案件を出してるのはうち（{自社名}）です。誰が出してるか分からない案件は載せてません」 |

### 4-2. 元請・工務店向け

**掴み**
> 「協力業者を探すとき、電話帳と紹介以外に手がないですよね。
> エリアと工種で探せて、謄本や保険を出してる会社かどうかも見えます」

**刺さる順番**
1. **支払いの実績が見える**（＝逆に、自社の実績も相手に見える）
2. 発注書類が全部アプリで完結
3. 応募を金額・信用・取引実績で並べ替えて比較できる

**元請には「探せる」より「見極められる」を売る。**
探すこと自体は困っていないが、**初めての会社を使うのが怖い**というのが本音。

### 4-3. 組合・協会向け

> 「組合員さんの受注機会を増やす仕組みとして、ご案内させてください。
> 組合経由でご登録いただいた方は、初月無料にします」

**組合には「団体としての利点」を出す**。加入メリットの1つとして扱ってもらう。

## 5. 広告バナー文言（Web・SNS）

すべて**案件そのもの**を主役にする。

| 型 | 文言 |
|---|---|
| 金額型 | 「千葉県市原市／足場1,240㎡／¥1,860,000／9月着工」 |
| 予定型 | 「次の現場、決まってますか。」 |
| 透明型 | 「1次か2次か3次か。案件ごとに出しています」 |
| 供給型 | 「公共事業も、民間工事も。下請案件が集まります」 |
| 逆張り型 | 「案件を探さない。空き情報を出しておくだけ」 |
| 書類型 | 「注文書も請求書も、スマホで。FAXはもう要りません」 |
| 価格型 | 「月2,980円。人工1回分の7分の1」 |
| 不安型 | 「初めての元請。支払いが期日どおりか、事前に分かります」 |

**避ける表現**
- 「公共工事」← 表記は「公共事業」で統一
- 「公共案件専門」「公共だけ」← 民間も扱うため誤認になる
- 「元請直だけ」「中間マージンなし」← 2次・3次もあるため誇大になる
- 「建設業DX」「業務効率化」「デジタル化」← 誰にも刺さらない
- 「オールインワン」「これ1つで完結」← 難しそうに聞こえる
- 「マッチングプラットフォーム」← 何屋か分からない

## 6-2. 先行登録フェーズ（公開前）

公開前は、登録の入口を**メールアドレス1つ**に絞る。特典は次の3つ。

| 特典 | 内容 |
|---|---|
| 優先案内 | 公開日にいちばん最初に案内する |
| **初月無料** | 最初の1か月は有料プランを無料で使える |
| 要望の反映 | 案件の掲載エリア・職種の希望を先に反映する |

### LINE配信（先行登録の告知）

> みなさんお疲れさまです。
>
> 前から言っていた案件のアプリ、まもなく公開します。
> 先行登録された方は**最初の1か月無料**でお使いいただけます。
>
> メールアドレスだけで登録できます。
> {URL}

### 登録数の見せ方

LPに「先行登録 受付中 ○社」を出しています。**実数を出すこと。**
盛った数字は、公開後に案件数や応募の反応と噛み合わなくなって必ずバレます。

少ないうちは「受付中」だけにして、数字は50社を超えたら出す、という運用でも構いません。

## 7. 配布・出稿の優先順位

| 順 | 施策 | 費用 | 期待 |
|---|---|---|---|
| 1 | **LINEコミュニティへの案件配信** | 0円 | 最初の100社はここで取る |
| 2 | 資材屋・リース屋の店頭ポスター | 印刷代のみ | 継続的に効く |
| 3 | 組合・協会への説明 | 交通費 | 一度に数十社 |
| 4 | 既存ユーザーからの取引先招待 | 0円 | アプリに機能あり |
| 5 | 建設系YouTube・Instagramへの案件提供 | 数万円 | 若い層に届く |
| 6 | Google広告（「足場 下請 募集」等） | 月5〜10万 | 母数が小さい。後回し |
| 7 | Meta広告 | — | 業種の絞り込みが弱い。**当面やらない** |

**1〜4だけで、しばらく戦えます。**
広告費をかけるのは、案件の供給が安定してからで十分です。

## 8. 効果の測り方

| 指標 | 見るもの |
|---|---|
| 登録数 | チャネル別。QRは配布場所ごとにパラメータを分ける |
| **初回の案件詳細の閲覧率** | 登録して案件を1件も見ない人は、ほぼ戻ってこない |
| **7日以内の応募率** | ここが低いと案件の質か件数の問題 |
| 空き情報の投稿率 | 供給側の在庫が育っているか |
| 有料転換率 | 書類の2枚目で止まった人が、どれだけ払うか |

**最初に見るべきは「初回の案件詳細の閲覧率」**です。
ここが低ければ、案件のエリアや工種が登録者と合っていません。
広告を増やす前に、案件の中身を直す必要があります。

## 9. まだ決めていないこと

- **サービス名**。LPでは仮に「ゲンバノワ」としています。決まり次第、全素材を差し替え
- **初月無料をやるか**。組合経由だけにするか、全員にやるか
- **紹介キャンペーン**。招待した相手が有料になったら1か月無料、など
- **元請向けのLPを分けるか**。刺さる文句が協力業者と全く違うので、分ける方が良さそう
