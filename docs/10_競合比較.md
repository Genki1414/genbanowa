## 2. 各社の要点

### 助太刀（最大の競合）

**強み**
- 22万超という圧倒的な母数。<cite>登録業者数22万人突破、47都道府県×82職種</cite>
- **あんしん払い**。工事代金を助太刀が立て替え、セブン銀行ATMで受け取れる。初めての取引先でも代金が確実に入る
- 相互評価が「腕がいい／話しやすい／約束をまもる」の3項目＋推薦文。**人柄まで見える**
- 求人（助太刀社員）まで持っていて、職人採用の入口になっている
- 国交大臣賞の受賞歴があり、公的な信頼が積み上がっている

**弱み・こちらが取れる余地**
- **有料の入口が19,800円と高い**。2026年4月にライトプランを月19,800円にリニューアルしています
- 一人親方や5人未満の会社には重い。実際、従業員5人未満向けの低価格プランを作った経緯自体が、
  「多機能でコストが見合わない」という声への対応でした
- **取ったあとの実務がない**。注文書も請求書も日報も写真もない
- 何次下請かは分からない

### ツクリンク

**強み**
- 無料で自社ページが持てる。**ホームページの代わり**になるのが刺さっている
- 個人事業主のメッセージプランが1,480円と安い
- 工事代金保証（月5,000円で200万まで／月9,800円で500万まで）
- 建材屋・金物屋の検索など、周辺サービスが厚い

**弱み・こちらが取れる余地**
- 法人のメッセージプランが14,800円で、**個人と法人の差が10倍**。小さい法人には割高
- こちらも「探すところまで」。書類の電子化はあるが、取引の流れとしては繋がっていない
- 何次下請かは分からない

### クラフトバンク

**強み**
- 案件掲載は無料。エリア・工種・物件ジャンルを問わず登録できる
- 面談サポートなど、人が介在する支援がある

**弱み**
- 約2万社と規模が小さい
- 有料プランが初回528,000円で、**個人事業主が手を出せる価格ではない**

## 3. ゲンバノワの立ち位置

```
        探す                取ったあと
        ────────────────────────────────
助太刀   ████████████████    （なし）
ツクリンク ███████████        ██（書類の電子化）
クラフト   ██████             （なし）
ゲンバノワ ████               ████████████████
```

**正面から「案件数」で勝つのは無理です。** 22万社と0社では勝負になりません。

勝ち筋は3つ。

### ① 価格帯が空いている

| 価格 | 誰がいるか |
|---|---|
| 1,480円 | ツクリンク（個人のみ） |
| **2,980円** | **← ここが空いている** |
| 14,800円 | ツクリンク法人 |
| 19,800円 | 助太刀ライト |
| 29,800円〜 | 助太刀ビジネス |

**法人でも2,980円**というのが効きます。ツクリンクは法人になった瞬間に14,800円、
助太刀は19,800円。**5人規模の会社が一番苦しいゾーン**に、まともな選択肢がありません。

### ② 「取ったあと」が空白地帯

3社とも探すところで終わっています。注文書も請求書も日報も写真も、
どこもやっていません。**仕事が取れなかった月に解約されない**のは、ここを持っている強みです。

### ③ 何次下請かを出しているのは、うちだけ

3社とも表示していません。単価に直結する情報なのに、聞かないと分からない。
**小さいが、誰もやっていない差別化**です。

## 4. 営業でこう聞かれたら

### 「助太刀使ってるけど、何が違うの？」

> 「助太刀さんは探すためのアプリです。うちは**取ったあとまで**やります。
> 注文書も請求書も日報も写真も、全部スマホで終わります。
>
> あと、助太刀さんは有料が19,800円からですけど、うちは2,980円です。
> 併用してもらって構いません。**探すのは助太刀、書類はうち**でも全然いいです」

**併用を勧めるのが要点。** 乗り換えを迫ると、22万社の実績と比べられて負けます。

### 「ツクリンクと何が違うの？」

> 「法人だとツクリンクさんは14,800円ですけど、うちは法人でも2,980円です。
> あと、何次下請かが案件ごとに出ます。ツクリンクさんは出ていません」

### 「登録数どれくらい？」

**正直に言う。** ごまかすと信用を全部失います。

> 「まだこれからです。今は{n}社で、案件は{n}件出ています。
> 数では助太刀さんに勝てません。ただ、うちは案件を自分たちでも出しているので、
> 数は少なくても**中身が見える案件**です。まず無料で中を見てもらえませんか」

### 「代金の立替はある？」

> 「ありません。助太刀さんの立替は確かに便利です。
> うちは**そもそも支払いが遅れる相手と組まない**ようにする方でやっています。
> 期日どおりに払っている会社かどうかが、事前に見えます」

**立替がないことを弱点として認めたうえで、別の解き方を提示する。**
ここで「立替なんて要らない」と言うと嘘くさくなります。

### 「アプリ苦手なんだけど」

> 「最初は画面が3つしかありません。使う理由ができたときに増えていきます。
> 全部おぼえる必要はないです」

## 5. 言ってはいけないこと

| ✕ | 理由 |
|---|---|
| 「助太刀より安い」を前面に出す | 安さで選ばれると、安いところに逃げられる |
| 「助太刀は探すだけ」と断じる | 事実だが、言い方次第で中傷になる。「うちは取ったあともやる」と自社主語で |
| 他社の登録数を実際より少なく言う | すぐバレる |
| 「立替もあります」 | ない |
| 「業界最大級」 | 嘘 |
| 他社の悪い口コミを持ち出す | 品位を落とすだけ。使わない |

**比較は「違い」を言う。「優劣」は言わない。**
判断は相手がします。
