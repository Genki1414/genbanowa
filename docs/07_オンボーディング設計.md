# ⑦ オンボーディング設計 v1

登録した人の大半は、最初の5分で使うかどうかを決める。
建設業のアプリで最も多い離脱理由は「入力が多い」と「何をすればいいか分からない」。

---

## 0. 設計の前提

**このアプリの「aha体験」は何か。**

候補は3つある。

| 候補 | 内容 | 到達までの時間 | 評価 |
|---|---|---|---|
| A | 案件が見つかる | 即（一覧を見るだけ） | 弱い。ツクリンクでもできる |
| B | **書類が1枚できる** | 3分 | **強い**。今までExcelでやっていたことが一瞬で終わる |
| C | スカウトが届く | 数日〜数週 | 強いが、待たせすぎる |

**Bを最優先にする。** 登録直後に「請求書が1枚できた」体験まで持っていく。
Cは後から効いてくるので、そこに繋ぐ準備（プロフィールを埋めさせる）を同時に仕込む。

---

## 1. 全体の流れ

```
① 電話番号でログイン（30秒）
      ↓
② あなたは？（3タップ）
      ↓
③ 会社の基本情報（1分）
      ↓
④ 最初の1件をつくる ← ここがaha
      ↓
⑤ 埋めると得することを提示
      ↓
⑥ ホームへ
```

**目標：登録開始から④の完了まで5分以内。**

---

## 2. 各ステップ

### ① ログイン（30秒）

- **電話番号＋SMS認証**を第一とする。メールは職人層で使われない
- パスワードは設定させない。次回もSMS
- LINEログインも並べる（後の通知連携が楽になる）

> メールアドレスを最初に聞かない。「会社のメールアドレスは？」で止まる人が実際にいる。

### ② あなたは？（3タップ）

大きなボタンを3つ。

```
┌─────────────────────┐
│  仕事を受ける側です  │  ← 協力業者
├─────────────────────┤
│  仕事を出す側です    │  ← 元請
├─────────────────────┤
│  どちらもやります    │
└─────────────────────┘
```

次に職種（複数選択）と、対応エリア（都道府県）。
**この3つだけ**で②は終わり。ここで会社名すら聞かない。

> この分岐で**以降の画面構成を変える**。
> 「出す側」を選んだ人にいきなり案件検索を見せても意味がない。

### ③ 会社の基本情報（1分）

| 項目 | 必須 | 理由 |
|---|---|---|
| 会社名 | ○ | 書類に必要 |
| 代表者名 | ○ | 書類に必要 |
| 所在地 | ○ | 書類に必要 |
| 電話番号 | 自動（①で取得） | — |
| 担当者名 | 任意 | 後で |
| 建設業許可 | **任意** | ここで聞くと止まる |
| 保険 | **任意** | 同上 |
| インボイス番号 | 任意 | 同上 |

**必須は4つだけ。** 許可番号や保険は⑤で「埋めると得する」として誘導する。

> ここで全部埋めさせようとすると、半分が離脱する。
> 書類を1枚作るのに最低限必要なものだけを聞く。

### ④ 最初の1件をつくる ← 最重要

②の選択によって出し分ける。

#### 「受ける側」を選んだ人

```
まずは請求書を1枚つくってみましょう
（普段お付き合いのある元請さん宛でかまいません）

  ┌──────────────────┐
  │  請求書をつくる   │
  └──────────────────┘
  ┌──────────────────┐
  │  見積書をつくる   │
  └──────────────────┘

  あとで
```

→ アプリ外書類の作成へ。宛先は「取引先を登録」から。
→ **できあがったPDFを見せる。ここがaha。**
→ 直後に「この取引先を招待しますか？」

#### 「出す側」を選んだ人

```
まずは協力業者さんを探してみましょう

  ┌──────────────────┐
  │ 会社を探す（○○県） │
  └──────────────────┘
  ┌──────────────────┐
  │ 案件を投稿する     │
  └──────────────────┘

  あとで
```

→ 会社一覧に、**自分のエリア×職種で絞った結果**を最初から表示。
→ 「◯◯県に足場屋が23社います」と件数を見せるのが効く。

#### 共通：現場の写真を1枚

```
現場の写真に黒板を入れてみましょう
（カメラを起動します）
```

これは**30秒で終わって、驚きがある**。
書類より軽いので、離脱しかけた人を引き戻す役割。

### ⑤ 埋めると得することを提示

④が終わった直後、モチベーションが高いうちに出す。

```
┌──────────────────────────────┐
│ プロフィールを埋めると          │
│ 元請から声が掛かりやすくなります │
│                              │
│ 現在の信用スコア  0点  未認証  │
│ ▓░░░░░░░░░░░░░░░░░░░░       │
│                              │
│ ☐ 建設業許可証      +15点     │
│ ☐ 社会保険の書類    +15点     │
│ ☐ 謄本             +20点     │
│                              │
│ ＋スカウトが読めるポイントも   │
│   もらえます                  │
└──────────────────────────────┘
```

**ここで初めて許可証と保険を聞く。**
「書類を出せ」ではなく「出すと得する」の順序にする。

### ⑥ ホームへ

初回のホームには**やることリスト**を出す。

```
はじめる前に（3/6 完了）
 ✓ 会社の情報を登録
 ✓ 最初の書類をつくる
 ✓ 現場写真を撮る
 ☐ 建設業許可を登録        +15点
 ☐ 対応エリアと職種を登録   +1ポイント
 ☐ 取引先を招待する
```

完了すると消える。全部終わるとメッセージが1回出て終わり。

## 3. 離脱しやすい箇所と対策

| 箇所 | 離脱理由 | 対策 |
|---|---|---|
| ① ログイン | SMSが届かない | 30秒で再送ボタン。3回失敗でLINEに誘導 |
| ③ 会社情報 | 入力が面倒 | 必須4項目のみ。住所は郵便番号から自動補完 |
| ③ 会社情報 | 許可番号が手元にない | **任意にする**。ここで聞かない |
| ④ 書類作成 | 宛先の登録が面倒 | 会社名だけで登録可。他は後から |
| ④ 写真 | カメラ権限を拒否 | 「写真を選ぶ」に自動でフォールバック |
| ⑤ 書類提出 | ファイルが手元にない | 「あとで通知します」を用意。3日後にリマインド |

## 4. 課金に当てるタイミング

無料のまま使っていて、**どこで壁に当たるか**を設計する。

| 日数 | 起きること | 感じること |
|---|---|---|
| 1日目 | 書類を1枚つくる | 便利だ |
| 2〜3日目 | 案件を3件見る → 4件目でロック | もっと見たい |
| 3〜7日目 | 2枚目の書類でロック | **これが本命の壁** |
| 1〜2週 | スカウトが1件届く → 読める | 嬉しい |
| 2週〜 | 2件目のスカウト → ポイント切れ | プロフィールを埋める |
| 3週〜 | プロフィールを埋め切る → 3件目が読めない | **課金** |

**書類の2枚目**が最初の壁。ここが最も転換率が高いはず。
案件の閲覧制限（月3件）は、実は転換のトリガーとしては弱い。
「見られなくても困らない」から。

> **重要**：無料で作れる書類を「1枚だけ」にするか「ゼロ」にするかは判断が要る。
> - **ゼロ**（現状）：aha体験が課金の後になる。転換率は落ちる
> - **1枚**：作る体験をしてもらってから壁に当てる。転換率は上がるが、1枚で満足されるリスク
>
> **私の意見は「初月に限り3枚まで無料」**。
> 作る体験を確実にさせて、月末に「来月から有料です」と当てる。
> aha体験の後に壁を置く方が、必ず転換率は高くなります。

## 5. 復帰の設計（使わなくなった人を戻す）

登録したまま使われないアカウントは必ず出る。

| 経過 | 送るもの |
|---|---|
| 3日 未ログイン | 「◯◯県で新しい案件が{n}件出ています」 |
| 7日 未ログイン | 「プロフィールがあと2つで完成します。スカウトが届きやすくなります」 |
| 14日 未ログイン | 「{同業他社}が今月{n}件受注しています」※匿名の集計 |
| 30日 未ログイン | 停止。以降は月1回の新着まとめのみ |

しつこくしない。**30日で諦める**。
それより、最初の7日で使わせる方に力を入れる。

## 6. 実装の優先度

| 優先 | 内容 |
|---|---|
| **高** | ①②③（電話番号ログイン・受発注の分岐・必須4項目） |
| **高** | ④の書類作成ルート |
| 中 | ⑤信用スコアの提示、⑥やることリスト |
| 中 | 郵便番号からの住所補完 |
| 低 | 復帰通知 |

**①〜④が通れば、オンボーディングとしては合格**。
⑤⑥は後から足せます。
